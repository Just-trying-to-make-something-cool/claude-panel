# Окно `c`: сначала сессии — план

> Исполнение: superpowers:executing-plans, исполнитель — эта же сессия (владелец сказал «бери в работу»).

**Goal:** окно открывается на списке всех сессий с поиском и подробностями справа; дерево папок — второй режим по Tab.

**Architecture:** данные (список сессий, имя, поиск, «кто работал в папке») — в `panel/core.py` без Textual;
окно `panel/tui.py` переписывается на два режима в `ContentSwitcher`. Запуск (`launch`, zellij) не меняется.

**Tech Stack:** Python 3.14, Textual 8.2.8 из `.venv` основной копии, unittest.

**Spec:** `docs/superpowers/specs/2026-11-08-sessions-first-design.md`

## Global Constraints

- Ядро работает на системном `python3` без Textual; панель только читает `~/.claude`.
- Без эмодзи и строки приветствия. Тема по умолчанию `nord`, `C_THEME` меняет.
- Прогоны без человека (`"entrypoint":"sdk-…"`) не показываются, кроме ждущих ответа.
- Текст с диска в разметку — только через `esc`.
- Тесты: `<main>/.venv/bin/python -m unittest discover -s tests` из рабочей копии.

## Review Focus

- Пустой поиск после ввода и стирания — список снова полный, выбран первый. Тест в задаче 2.
- Запрос без совпадений — пустой список и строка «ничего не нашлось», Enter ничего не запускает. Задача 2.
- Сессия из поиска открывается из своей папки запуска, а не из корня (`claude -r` ищет стенограмму по cwd). Задача 2.
- Две сессии с одинаковым именем различимы: подробности справа меняются при ↑↓. Задача 2.
- Продолжение после предела контекста без названия не подписывается служебной фразой. Задача 1.

### Задача 1: данные для списка и поиска (core.py)

**Files:** `panel/core.py`, `tests/test_sessions.py`

**Produces:**
- `session_brief(f)` дополнительно отдаёт `auto: bool` (голова, `_AUTO`) и `last_user: str` (последняя реплика человека из уже читаемого хвоста; файл ≤ HEAD — из головы).
- `display_name(b: dict, row: Row) -> str`: срез «<row.project> · » / «<row.label> · »; пустое, равное `row.label`/`row.project` или «<label> (N)» → первая строка `first`; если `first == CONTINUED` → первая строка `last_user`, иначе «продолжение прошлой сессии»; пусто → «без имени».
- `all_sessions(rows) -> list[dict]`: `{'brief', 'row', 'name', 'live'}` по всем видимым папкам (без `agent-*`), без `auto` кроме `live['blocked']`; порядок: ждущие ответа, потом `brief['last']` по убыванию.
- `find_sessions(items, query) -> list[dict]` и `find_folders(rows, query, limit=5) -> list[Row]`: слова запроса (регистр и ё/е не важны) все входят в стог: имя, название, первый и последний запрос, имя и описание папки (для папок — имя и описание). Папки: глубина ≥ 1, свежие выше.
- `Row.visitors: list[str]` — файлы сессий корня/сегментов с долей `cwd` в папке ≥ 10%, заполняет `add_activity` тем же проходом.

- [ ] Тесты: `test_brief_marks_robot_and_last_prompt`, `test_display_name_*` (срез приписки, имя=папка, «(2)», продолжение, пустое), `test_all_sessions_hides_robots_waiting_first`, `test_find_sessions_all_words_case_yo`, `test_find_folders_by_description`, `test_visitors_from_root_session`.
- [ ] Прогнать — падают; реализовать; прогнать — зелёные; мутационные пробы на робота, порядок, AND слов; коммит.

### Задача 2: режим «Сессии» (tui.py)

**Files:** `panel/tui.py`, `tests/test_tui.py`
**Consumes:** всё из задачи 1, `open_action`, `session_detail`, `esc`.

- Сверху строка режимов «Сессии · Папки»; `ContentSwitcher` с `#sessions` и `#folders`.
- `#sessions`: `Input#q` (фокус при запуске), `OptionList#list` (имя слева, справа «ждёт ответа»/«идёт»/«робот» и `when`), `Static#detail` справа (где запущена и где работала, когда, первый/последний запрос, последний ответ, чем кончилась; подробности — в фоне, как `load_one`). Совпадения подсвечены.
- Под сессиями при запросе — заголовок «Новая сессия в папке» (неактивная строка) и папки из `find_folders`.
- ↑↓/PgUp/PgDn из строки поиска двигают выбор; Enter — открыть сессию (`open_action` по живым её папки; `busy:` — предупреждение) или новую в папке (поле имени, как в задаче 3); Esc — очистить, на пустом — выход; Tab — «Папки».
- Карточки читаются в фоне (`@work(thread=True)`), до готовности — «читаю сессии…».

- [ ] Тесты на фикстурах (корень во временной папке, `c.PROJECTS` подменён): открытие в режиме сессий с фокусом на поиске; роботы скрыты; ввод «лид» сужает и показывает папку; стереть — полный список; нет совпадений — Enter ничего не делает; Enter открывает выбранную из её папки; ↓ + Enter — вторая; Esc очищает, второй Esc — выход; живая фоновая → `bg:`; открытая в другом терминале → предупреждение; «[» в имени не роняет.
- [ ] Красные → реализация → зелёные → пробы (Enter открывает не выбранную, фильтр игнорирует слово) → коммит.

### Задача 3: режим «Папки» (tui.py)

**Files:** `panel/tui.py`, `tests/test_tui.py`
**Consumes:** `ordered`, `is_fresh`, `Row.visitors`, `session_name`.

- Дерево как в main (свежие сверху, «давно не открывались · N», части), без эмодзи.
- Справа: имя, описание, где живёт; кнопки «Новая сессия здесь» и «Продолжить последнюю»; «Работа над этой папкой» — свои человеческие сессии + `visitors`, свежие первыми, с пометкой «из <папки>».
- Enter на проекте/корне — поле «о чём сессия» → Enter запускает `new` с `session_name(row, текст)`; на сегменте и группе — раскрыть; `c` — продолжить последнюю; → — к списку работы, Enter там открывает; Tab — «Сессии»; Esc — назад/выход; q — выход.

- [ ] Тесты: Tab переключает и обратно; группы «давно не открывались» (перенос из main); Enter на сегменте раскрывает; Enter на проекте → поле → «takt · бизнес»; `c` → continue; сессия-гость из корня видна в работе папки и открывается из корня.
- [ ] Красные → реализация → зелёные → коммит.
