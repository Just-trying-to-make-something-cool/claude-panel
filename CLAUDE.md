# claude-panel — панель управления папками Claude

Окно в терминале (Textual), запускающее Claude Code в выбранной папке `~/claude`. Команда `c`.
Описание, установка и устройство: `README.md`. Память: `tool_c_launcher.md`.

## Правила
- Ядро (`panel/core.py`) не зависит от Textual и работает на системном `python3`: так живут `--list`, `--dry`, `--fzf`. Окно (`panel/tui.py`) только из `.venv`.
- Список мест запуска выводится из дерева папок и таблиц CLAUDE.md. Конфиг-файл со списком проектов не заводить: он разойдётся с диском.
- Панель только читает `~/.claude`. Переносить, переименовывать или удалять сессии она не должна.
- Перед сдачей: `.venv/bin/python -m unittest discover -s tests` зелёный, и один снимок окна глазами (`save_screenshot` → `qlmanage`), потому что тесты не видят вёрстку.
- Прод — это символьная ссылка `~/.local/bin/c` на `bin/c` этого репозитория. Переустановка: `./install.sh`.
